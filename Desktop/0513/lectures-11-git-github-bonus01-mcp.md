## 왜 코드를 저장하는 것만으로는 부족한가?

여러분은 지금까지 코드를 내 PC에서만 작업했습니다.  
Ctrl+S로 파일을 저장하면 되는 거 아닌가?

왜 추가적인 도구가 필요할까요?

### 문제 1: 되돌리기가 안 됩니다
어제까지 잘 돌아가던 코드를 오늘 수정했는데 망가졌습니다.  
Ctrl+Z를 미친 듯이 눌러도 어제 상태로 돌아갈 수 없습니다.

### 문제 2: PC가 고장 나면 끝입니다
SSD가 갑자기 죽으면? 커피를 쏟으면? 코드가 내 PC에만 있으면 모든 게 사라집니다.

### 문제 3: 배포하려면 코드가 인터넷에 있어야 합니다
앞으로 만들 고구마마켓을 인터넷에 배포하려면, 코드를 클라우드에 올려야 합니다.

## Git과 GitHub — 게임의 세이브 포인트

RPG 게임을 해본 적 있나요?

- **Git** = 게임 내 세이브 포인트 기능. 언제든 저장하고, 원하는 시점으로 되돌릴 수 있습니다.
- **GitHub** = 세이브 데이터를 클라우드에 백업하는 것. PC가 망가져도 다른 기기에서 이어할 수 있습니다.

| | Git | GitHub |
|---|---|---|
| **역할** | 코드 변경 기록을 관리 | Git 기록을 인터넷에 저장 |
| **위치** | 내 PC에서 동작 | 웹사이트 (github.com) |
| **비유** | 게임 세이브 기능 | 클라우드 세이브 백업 |
| **필요성** | 되돌리기, 변경 추적 | 백업, 협업, 배포 |

> **핵심: Git으로 저장하고, GitHub에 백업한다.**

## Git 기본 설정

Git을 처음 사용하면 이름과 이메일을 등록해야 합니다.  
이 정보는 **누가 이 코드를 저장했는지** 기록하는 용도입니다.

```
git config --global user.name "홍길동"
git config --global user.email "hong@example.com"
```

이름과 이메일은 자유롭게 적으면 됩니다.  
나중에 GitHub에서 보이는 이름이니, 본인이 알아볼 수 있는 걸로 하세요.

### 확인

```
git config --global user.name
git config --global user.email
```

본인이 입력한 값이 나오면 성공입니다.

## Git의 핵심 개념 4가지

사실 클코가 Git 명령어를 전부 대신 쳐주지만, 의미는 알아두면 대화할 때 편합니다.

택배 보내기에 비유해볼게요:

| 단계 | Git 명령어 | 비유 | 설명 |
|---|---|---|---|
| 1 | `git init` | 택배 상자 준비 | 이 폴더를 Git으로 관리하겠다고 선언 |
| 2 | `git add .` | 물건 담기 | 변경된 파일들을 "보낼 준비" |
| 3 | `git commit` | 포장 + 송장 붙이기 | 변경 내용을 메시지와 함께 기록 |
| 4 | `git push` | 택배 발송 | GitHub에 업로드 |

```
작업 → add(담기) → commit(포장) → push(발송)
```

이 흐름을 외울 필요 없습니다. 클코가 알아서 해줍니다.  
다만 클코가 "커밋하겠습니다", "푸시하겠습니다" 할 때 무슨 뜻인지 알면 됩니다.

## GitHub CLI (gh) 설치 및 로그인

클코가 GitHub에 코드를 올리려면 **gh CLI**라는 도구가 필요합니다.  
`gh`는 터미널에서 GitHub를 사용할 수 있게 해주는 프로그램입니다.

### 설치

```
winget install --id GitHub.cli
```

`winget`이 안 된다면? (Windows 10 구버전에서는 winget이 없을 수 있습니다)

1. https://cli.github.com 에 접속
2. Download for Windows 클릭
3. 설치 파일 실행 → Next → Install → Finish
4. PowerShell을 새로 열고 아래 명령어로 확인

**설치 확인:**

```
gh --version
```

### 로그인

```
gh auth login
```

아래처럼 물어봅니다. 하나씩 선택해주세요:

```
? What account do you want to log into?  →  GitHub.com
? What is your preferred protocol?       →  HTTPS
? Authenticate Git with your GitHub credentials?  →  Yes
? How would you like to authenticate?    →  Login with a web browser
```

마지막에 8자리 코드가 나옵니다. 브라우저가 열리면 그 코드를 입력하고 Authorize 버튼을 누르세요.

```
✓ Authentication complete.
```

이 메시지가 나오면 성공입니다!

## 클코에게 GitHub 올리기 시키기

여기가 이 챕터의 핵심입니다.  
위에서 배운 init, add, commit, push를 직접 칠 필요 없습니다.

### 프롬프트

```
이 프로젝트 GitHub에 올려줘.
저장소 이름은 goguma-market으로 해줘.
```

클코가 알아서 해주는 것들:

1. `git init` — 프로젝트를 Git으로 관리 시작
2. `.gitignore` 생성 — 올리면 안 되는 파일 자동 제외
3. `git add .` + `git commit` — 파일 담고 포장
4. GitHub에 새 저장소(repository) 생성
5. `git push` — 코드 업로드

### 결과 확인

클코가 완료하면 GitHub 주소를 알려줍니다:

```
https://github.com/내사용자명/goguma-market
```

이 주소를 브라우저에서 열어보세요. 내 코드가 인터넷에 올라가 있습니다!

## 자주 발생하는 문제 (Chapter 11)

| 증상 | 원인 | 해결 |
|---|---|---|
| `gh: command not found` | gh CLI 미설치 | `winget install --id GitHub.cli` 후 터미널 재시작 |
| gh auth login 시 브라우저 안 열림 | 기본 브라우저 문제 | 터미널에 나온 URL을 직접 복사해서 브라우저에 붙여넣기 |
| `git: command not found` | Git 미설치 | https://git-scm.com 에서 설치 |
| Permission denied | GitHub 로그인 안 됨 | `gh auth login` 다시 실행 |
| repository not found | 저장소 이름 오타 | 클코에게 "GitHub 저장소 다시 만들어줘" |
| Author identity unknown | Git 이름/이메일 미설정 | 위의 `git config` 명령어 실행 |

## Chrome DevTools MCP — 클코가 실제 크롬 창을 잡는다

이 MCP를 연결하면, 클로드 코드가 **내 PC에 깔린 크롬 창을 직접 잡고 움직입니다.**

| 항목 | 동작 |
|---|---|
| 사용하는 브라우저 | 내 PC에 평소 쓰는 크롬 그대로 |
| 진행 모습 | 눈앞에서 자동으로 움직이는 게 보임 |
| 주된 용도 | 직접 보면서 하는 자료 수집·반복 작업 |

- 공식 저장소: https://github.com/ChromeDevTools/chrome-devtools-mcp
- 메인테이너: ChromeDevTools 조직 (Google)

### 무엇을 할 수 있나

- 페이지 열고 클릭하기
- 폼에 텍스트 자동 입력

## 노션이 처음이라면 — 짧은 소개

Notion MCP를 보기 전에, 노션 자체를 짧게 소개합니다. 이미 노션을 쓰고 계시면 이 섹션은 건너뛰셔도 됩니다.

### 노션은 어떤 도구인가

**노션(Notion)** 은 한 화면 안에서 메모·문서·할 일·표·캘린더를 모두 다룰 수 있는 도구입니다.  
워드·엑셀·구글캘린더·메모장을 하나로 합쳐놓은 느낌입니다. 무료로 시작할 수 있습니다.

### 세 가지 기본 개념

| 용어 | 무엇 |
|---|---|
| 워크스페이스 | 내 노션 전체 공간 (이메일 하나당 하나) |
| 페이지 | 한 장의 문서. 글·이미지·체크박스·표를 자유롭게 배치 |
| 데이터베이스 | 여러 페이지를 표·갤러리·캘린더로 모아 보는 형태. 엑셀과 비슷하지만 각 행 자체가 하나의 페이지 |

가장 많이 쓰이는 활용:
- 회의록 모아두기
- 독서·영화 기록
- 할 일 목록과 마감 관리
- 출장·여행 일정 정리
- 위키처럼 회사·팀 정보 모아두기

### 가입하고 첫 페이지 만들기

1. https://www.notion.com 접속
2. 이메일 또는 구글 계정으로 가입 (개인 사용은 무료)
3. 왼쪽 사이드바에서 "+ 새 페이지" 클릭
4. 제목을 적고 본문에 글을 쓰거나, `/` 를 입력하면 표·할 일·이미지 등 블록을 골라서 넣을 수 있음

이 정도만 알면 다음 섹션을 따라올 수 있습니다.

## Notion MCP — 노션을 클코가 정리해준다

노션을 사용하고 있다면 바로 활용할 수 있는 MCP입니다.  
"노션에 회의록 데이터베이스 만들고, 오늘 회의 내용 정리해서 넣어줘" 한 줄이면 됩니다.

- 공식 저장소: https://github.com/makenotion/notion-mcp-server
- 메인테이너: Notion (makenotion)
- 권장: Remote MCP (OAuth 기반) 사용

### 무엇을 할 수 있나

- 페이지·데이터베이스 만들기
- 데이터 추가·수정·검색
- 회의록·할 일·독서 기록 자동 정리
- 다른 노션 페이지 내용 가져와서 요약

### 설치 — .mcp.json 파일 한 개

프로젝트 폴더에 `.mcp.json` 이라는 파일을 만들고 아래 내용을 적어 저장합니다.

```json
{
  "mcpServers": {
    "notion": {
      "type": "http",
      "url": "https://mcp.notion.com/mcp"
    }
  }
}
```

직접 만들기 번거로우면 클로드 코드에게 시켜도 됩니다.

```
이 프로젝트에 노션 MCP를 연결하는 .mcp.json 파일 만들어줘.
type은 http, url은 https://mcp.notion.com/mcp 로.
```

파일이 만들어지면 클로드 코드를 다시 시작하고, 안에서 `/mcp` 를 입력합니다.  
OAuth 인증 페이지가 브라우저로 열리고, 노션에 로그인 후 워크스페이스 접근을 허용하면 연결이 완료됩니다.

> **참고:** `.mcp.json` 은 **이 프로젝트 폴더에서만** 동작합니다. 다른 프로젝트에서 노션을 또 쓰고 싶다면 그 폴더에도 같은 파일을 만들어주면 됩니다.

### 함께 해볼 시연

연결이 끝났으면 세 가지 시연을 차례로 해봅니다.  
모두 클로드 코드에 한 번에 적어 보내는 프롬프트입니다.

#### 시연 1 — 회의록 데이터베이스 + 첫 회의 기록

```
노션에 "회의록" 데이터베이스 만들어줘.
컬럼:
- 날짜 (Date)
- 제목 (Title)
- 참석자 (Multi-select)
- 내용 (Text)
- 액션 아이템 (Text)

만들고 나서 오늘 점심 회의 한 건 넣어줘.
참석자는 김부장, 이대리, 나. 주제는 4월 마감 일정 점검.
액션 아이템은 그럴듯한 걸로 두 개 만들어줘.
```

노션을 새로고침하면 DB와 첫 데이터가 들어가 있습니다.

#### 시연 2 — 외부 자료 조사 → 노션에 정리

```
"전기차 보조금 2026년 변경 사항" 찾아서 핵심만 5줄 이내로 요약해줘.
요약과 출처 링크를 노션에 "전기차 보조금 2026" 페이지로 만들어서 넣어줘.
```

클로드 코드가 웹 검색 → 요약 → 노션 페이지 생성을 한 흐름에 처리합니다.

#### 시연 3 — 노션 안 데이터 검색·정리

```
방금 만든 회의록 DB 안에서 액션 아이템이 있는 회의를 모두 찾아서
"누가 무엇을 언제까지" 형태의 표로 정리해줘.
```

노션 안의 데이터를 클로드 코드가 직접 읽어 와서 정돈된 답변으로 돌려줍니다.

## 본인 시나리오 — 한두 개 골라 실습

이번엔 본인이 평소 정리하고 싶었던 영역을 한두 개 골라 진행합니다.  
시나리오 카드를 보고 본인에게 가까운 걸 고르세요.

| # | 시나리오 | 결과물 |
|---|---|---|
| 1 | 회의록 자동 정리 | "회의록" DB + 이번 주 회의 3건 |
| 2 | 독서·영화 기록 | "기록" DB + 최근 본 책·영화 5개 한 줄 요약 |
| 3 | 할 일 정리 | "할 일" DB + 흩어진 메모에서 할 일 정리 |
| 4 | 여행·휴가 계획 | "다음 휴가" 페이지 + 도시·맛집·일정 |
| 5 | 위키 페이지 | 자주 찾는 정보 한 페이지로 (단축키·자주 가는 사이트 등) |
| 6 | 인용구·문장 모음 | "오늘의 한 줄" DB + 최근 인상 깊었던 인용구들 |

### 시작 프롬프트 — 6개 카드

**1. 회의록 자동 정리**
```
노션에 "회의록" 데이터베이스 만들어줘.
컬럼: 날짜, 제목, 참석자(multi-select), 내용(text), 액션 아이템(text).
그 다음 이번 주 회의 세 건을 채워줘. 내가 줄게:
1. (회의 정보)
2. (회의 정보)
3. (회의 정보)
```

**2. 독서·영화 기록**
```
노션에 "기록" 데이터베이스 만들어줘.
컬럼: 제목, 분류(책/영화/드라마), 한 줄 요약, 별점(1~5), 기록일.
다섯 개 채워줘. 분류·제목·별점은 내가 알려주고, 한 줄 요약은 잘 만들어줘.
- 책 "트렌드 코리아 2026" / 별점 4
- 영화 "범죄도시 5" / 별점 3
- ...
```

**3. 할 일 정리**
```
노션에 "할 일" 데이터베이스 만들어줘.
컬럼: 제목, 마감일(date), 상태(select: 대기/진행/완료), 우선순위(select: 높음/중간/낮음).
내가 적어주는 할 일 5개를 채워줘.
1. 다음 주 화요일까지 보고서 작성 — 높음
2. 이번 달 안에 가전제품 보증서 정리 — 낮음
3. ...
```

**4. 여행·휴가 계획**
```
노션에 "다음 휴가 — 부산" 이라는 페이지 만들어줘.
페이지 안에 섹션 4개 만들어줘:
- 일정 (날짜별 토글)
- 가고 싶은 곳 (체크리스트)
- 맛집 후보 (표: 이름, 주소, 가본 적 있는지, 메모)
- 준비물

"부산 2박3일 휴가" 기준으로 가고 싶은 곳 5개, 맛집 5개 후보를 검색해서 채워줘.
```

**5. 위키 페이지**
```
노션에 "내 위키" 페이지 만들어줘.
섹션:
- 자주 가는 사이트 (불릿 + 링크)
- 단축키 모음 (표: 도구, 단축키, 무엇을 할 때)
- 자주 쓰는 명령어 (코드 블록)

자주 가는 사이트 5개와 자주 쓰는 명령어 3개는 내가 알려줄게.
```

**6. 인용구·문장 모음**
```
노션에 "오늘의 한 줄" 데이터베이스 만들어줘.
컬럼: 인용구, 출처, 분류(책/영화/대화/기타), 기록일.
다섯 개 채워줘. 내가 줄게:
1. "..." — 출처
2. "..." — 출처
```

### 막힐 때

| 증상 | 해결 |
|---|---|
| 페이지·DB가 안 만들어짐 | 클로드 코드에서 `/mcp` 다시 입력해 OAuth 재인증 |
| "권한이 없습니다" 메시지 | OAuth 진행 시 워크스페이스 접근을 허용했는지 확인 |
| 만든 DB가 사이드바에 안 보임 | 노션 사이드바 "공유됨" 섹션 또는 검색(Ctrl+P)으로 찾기 |
| 응답이 영어로 옴 | 프롬프트 마지막에 "한국어로 답해줘" 한 줄 추가 |

### 결과 공유

만든 결과 중 하나를 짧게 공유합니다. 어떤 프롬프트가 잘 통했고, 어디서 막혔는지 함께 정리합니다.

이 흐름이 익숙해지면 다음 챕터(B2)에서 외부 자료 조사 자체를 노션이나 로컬 폴더에 그대로 쌓을 수 있습니다.

## 두 MCP를 묶어서 보기

```
Chrome DevTools MCP → 화면을 보면서 작업 / 자료 수집
Notion MCP         → 정리 / 저장 / 협업
```

둘 다 "외부 서비스에 손을 달아주는 표준"이라는 점은 같지만, 각자 책임지는 단계가 다릅니다.

```
수집  →  정리
크롬     노션
```

뒤에 나오는 B2(지식 수집)·B3(AI 인터뷰)·B4(프로필 페이지)도 같은 흐름의 변주입니다.
